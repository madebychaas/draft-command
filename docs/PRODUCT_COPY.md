## “How it thinks” — public-safe

Draft Command combines:

- live draft state
- league-specific context
- player value
- market behavior
- timing pressure

to produce a recommendation for the decision **right now**.

The private model determines how those signals are combined. The public product exposes the decision, the rationale, and the trust boundary — not the competitive recipe.

## “Why it is different”

### Static rankings answer the wrong question
A ranking tells you who is better in the abstract. Draft Command is built to determine which action makes the most sense **now**.

### Timing is part of the decision
The system considers the cost of waiting, not just present value.

### The board is a market
Other managers are independent actors consuming scarce options.

### Confidence is earned
If the system cannot establish trustworthy inputs, it can withhold a recommendation.

### AI assists; proof decides
AI helps build, critique, and explain. Deterministic evidence governs numerical truth and production changes.

## LinkedIn project description

Built **Draft Command**, a real-time adversarial decision-intelligence system using fantasy football as the proving ground.

The product treats a live draft as a sequential, partially observable competitive market rather than a rankings problem. Deterministic code owns numerical truth; probabilistic simulation represents uncertainty; AI assists with engineering, adversarial review, and explanation.

The user experience stays intentionally simple: one recommendation, immediate backups, a concise why, a signal on the cost of waiting, and confidence only when the evidence supports it.

The bigger idea: use AI to redesign the machinery around human judgment — not replace the judgment itself.
